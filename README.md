# iPod + Spotify

Standalone mobile-first iPod player project. It lives in its own repository, separate from Camino de Santiago.

## Controls

- When playback is paused, swipe in a circle around the wheel to move through Spotify. Press the center button to open the highlighted item.
- While music is playing, turn the wheel clockwise to raise the volume and counterclockwise to lower it. Press the center button to pause/resume.
- Track skipping is available in Spotify's embedded player. Wheel volume control requires Spotify Premium and an active Spotify device.

## Publish with GitHub Pages

1. Create a new, empty GitHub repository named `ipod-classic-spotify` under `andreivasileplesa-hash`.
2. In **Settings → Pages**, set the build source to **GitHub Actions**.
3. From this folder, run `git push -u origin main`. The included workflow publishes the site at `https://andreivasileplesa-hash.github.io/ipod-classic-spotify/`.
